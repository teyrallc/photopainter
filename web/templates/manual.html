{{ t.assembly_guide }}

  1. Flash Raspbian Bookworm Lite to microSD
  2. Configure WiFi and enable SSH via raspi-config
  3. Insert Pi Zero 2 W into the PhotoPainter carrier board
  4. Verify e-paper ribbon cable connection
  5. Power on
SPI must be enabled!
sudo raspi-config → Interface Options → SPI → Enable

{{ t.troubleshooting }}

  1. Verify SPI is enabled: sudo raspi-config → Interface Options → SPI
  2. Check ribbon cable connection
  3. Send test pattern from Dashboard
  4. Ensure service runs as root (SPI/GPIO requires root)

  1. Check service: sudo systemctl status vignette
  2. Check IP: hostname -I
  3. Ensure same WiFi network
  4. Check port: sudo ufw allow 5000

  • Normal operating temperature: ~40-60°C
  • Recommend adding a heatsink
  • Monitor: vcgencmd measure_temp
