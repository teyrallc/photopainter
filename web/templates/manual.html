硬體需求 / Hardware Requirements

主控板 / BoardRaspberry Pi Zero 2 W
背板 / CarrierWaveshare RPi Zero PhotoPainter Board
顯示器 / DisplayWaveshare 7.3" 6-color e-paper (800 x 480)
電池 / Battery3.7V 1500mAh Li-Po
記憶卡 / Storage32GB+ microSD (64GB recommended)
顯示色彩 / ColorsBlack, White, Green, Blue, Red, Yellow, Orange (7 colors)
解析度 / Resolution800 x 480 pixels
刷新時間 / Refresh~12 seconds

組裝說明 / Assembly

  1. 燒錄 Raspbian Bullseye Lite 到 microSD 卡 / Flash Raspbian Bullseye Lite to microSD
  2. 設定 WiFi 及啟用 SSH / Configure WiFi and enable SSH via raspi-config
  3. 將 Pi Zero 2 W 插入 PhotoPainter 背板 / Insert Pi Zero 2 W into the PhotoPainter carrier board
  4. 確認電子紙排線連接正確 / Verify e-paper ribbon cable connection
  5. 接上電源啟動 / Power on
SPI 必須啟用！/ SPI must be enabled!
sudo raspi-config → Interface Options → SPI → Enable

軟體安裝 / Installation

一鍵安裝 / One-command Install
git clone https://github.com/teyrallc/photopainter.git
cd photopainter
bash scripts/install.sh
安裝內容 / What Gets Installed
  • 系統套件 / System packages: cmake, python3, git, OpenCV, etc.
  • Python 虛擬環境及依賴 / Python virtual environment and dependencies
  • systemd 服務（開機自動啟動） / systemd service (auto-start on boot)

Web 控制台 / Web Console

安裝完成後，Web 介面會自動啟動。/ After installation, the web interface starts automatically.

在同一網路的任何裝置上開啟瀏覽器：/ Open a browser on any device on the same network:

http://<Pi-IP>:5000

範例 / Examples
# Upload image / 上傳圖片
curl -F "file=@photo.jpg" http://pi:5000/api/upload

# Display on e-paper / 顯示到電子紙
curl -X POST -H "Content-Type: application/json" \
  -d '{"filename": "photo.jpg"}' http://pi:5000/api/display

# Next photo / 下一張照片
curl -X POST http://pi:5000/api/photo/next

# Test pattern / 測試圖案
curl -X POST http://pi:5000/api/display/test

服務管理 / Service Management

Vignette 以 systemd 服務運行，開機自動啟動。/ Vignette runs as a systemd service, auto-starts on boot.

# 查看狀態 / Check status
sudo systemctl status vignette

# 重啟服務 / Restart service
sudo systemctl restart vignette

# 停止服務 / Stop service
sudo systemctl stop vignette

# 查看日誌 / View logs
journalctl -u vignette -f
遠端管理 / Remote Management
  • Web 介面 / Web UI: 在控制台點擊「遠端更新程式」、「重新啟動」或「關機」 / Use Dashboard buttons
  • SSH: bash scripts/update.sh

故障排除 / Troubleshooting

  1. 確認 SPI 已啟用 / Verify SPI is enabled: sudo raspi-config → Interface Options → SPI
  2. 檢查排線連接 / Check ribbon cable connection
  3. 使用測試圖案驗證 / Send test pattern from Dashboard or: curl -X POST http://localhost:5000/api/display/test
  4. 確認服務以 root 運行 / Ensure service runs as root (SPI/GPIO requires root)

  1. 確認服務運行中 / Check service status: sudo systemctl status vignette
  2. 確認 Pi 的 IP / Check Pi IP: hostname -I
  3. 確認同一 WiFi 網路 / Ensure same WiFi network
  4. 確認 port 5000 未被阻擋 / Check port 5000: sudo ufw allow 5000
  5. 嘗試本機存取 / Try locally: curl http://localhost:5000

  • 正常運行溫度約 40-60°C / Normal operating temperature is ~40-60°C
  • 建議加裝散熱片 / Recommend adding a heatsink
  • 監控溫度 / Monitor: vcgencmd measure_temp

  1. 確認 Pi 有網路連線 / Check network: ping google.com
  2. 確認 git remote / Check remote: git remote -v
  3. 手動更新 / Manual update: cd photopainter && git pull && sudo systemctl restart vignette
