{{ t.assembly_guide }}

  1. Flash Raspberry Pi OS Bookworm Lite to the microSD card.
  2. Configure WiFi and enable SSH with raspi-config.
  3. Seat the Pi Zero 2 W in the PhotoPainter carrier board.
  4. Check the e-paper ribbon cable is fully inserted and latched.
  5. Power on.
{{ icon('info') }} SPI must be enabled — sudo raspi-config → Interface Options → SPI → Enable.

{{ t.troubleshooting }}

  1. Confirm SPI is enabled: sudo raspi-config → Interface Options → SPI.
  2. Reseat the ribbon cable at both ends.
  3. Send the test pattern from the dashboard.
  4. The service needs root — SPI and GPIO access require it.
  1. sudo systemctl status vignette — is the service running?
  2. hostname -I — confirm the address you are dialling.
  3. Both devices must be on the same network (and the Pi on 2.4 GHz).
  4. If a firewall is enabled: sudo ufw allow 5000.
  • 40–60 °C is normal for a Pi Zero 2 W under this workload.
  • A small heatsink helps in an enclosed frame.
  • Check with vcgencmd measure_temp, or watch the dashboard.
  • The radio is 2.4 GHz only — a 5 GHz-only SSID will never appear.
  • After sending the password the hotspot shuts down; your phone has to rejoin your home WiFi before the setup page can find the device again.
  • If the password was wrong, the Vignette-Setup hotspot restarts on its own so you can retry.
  • The e-paper panel always shows the address it ended up on.
