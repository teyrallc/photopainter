使用手冊

硬體需求 組裝說明 軟體安裝 Web 控制台 命令列使用 自動排程 按鍵控制 API 文件 故障排除

硬體需求

主控板Raspberry Pi Zero 2 W
顯示器Waveshare 7.3 吋 6 色電子紙 (800 x 480)
記憶卡32GB 以上 microSD 卡 (建議 64GB)
電源5V/2A micro USB 電源供應器
散熱建議加裝散熱片 (AI 生成時溫度可達 70°C)
顯示色彩黑、白、綠、藍、紅、黃、橘 (7 色)
解析度800 x 480 像素
刷新時間約 12 秒

組裝說明

  1. 將 microSD 卡燒錄 Raspbian Bullseye Lite 系統
  2. 設定 WiFi 及啟用 SSH（透過 raspi-config）
  3. 將 Raspberry Pi Zero 2 插入 Waveshare PhotoPainter 背板
  4. 確認電子紙排線連接正確
  5. 接上電源啟動
SPI 介面必須啟用！請執行 sudo raspi-config → Interface Options → SPI → Enable

軟體安裝

一鍵安裝
# 下載專案
git clone https://github.com/teyrallc/photopainter.git
cd photopainter

# 執行安裝腳本（需要數小時）
bash scripts/install.sh
安裝內容
  • 系統套件：cmake, python3, git, OpenCV 等
  • Python 虛擬環境及所有套件
  • OnnxStream 框架編譯（Stable Diffusion 推理引擎）
  • Stable Diffusion XL Turbo 模型下載（約 8GB）
安裝過程需要數小時（主要是模型下載和編譯）。請確保網路穩定。

Web 控制台

啟動 Web 伺服器
# 啟動 Web 介面
cd photopainter
source venv/bin/activate
python web/app.py

啟動後，在同一網路的裝置上開啟瀏覽器，輸入：

http://<你的Pi的IP>:5000
功能說明
頁面功能
控制台顯示器狀態、快速操作、最近圖片
上傳圖片拖曳上傳、預覽原圖及電子紙效果、一鍵顯示
AI 生成選擇提示詞模板或自訂、設定參數、即時進度
圖庫瀏覽所有圖片、預覽/顯示/刪除

命令列使用

生成圖片
# 使用隨機提示詞生成
python src/generate_picture.py output/

# 使用自訂提示詞
python src/generate_picture.py output/ --prompt "a beautiful sunset as an oil painting"

# 使用風景模板
python src/generate_picture.py output/ --prompts prompts/landscapes.json

# 指定 seed 和步數
python src/generate_picture.py output/ --seed 42 --steps 8
顯示圖片
# 顯示到電子紙
python src/display_picture.py output/output.png

# 智慧裁切並顯示
python src/display_picture.py some_photo.jpg

# 模擬模式（不需要電子紙硬體）
python src/display_picture.py image.png -s -o preview.png

# 產生 7 色量化預覽
python src/display_picture.py image.png -s -q -o preview.png

自動排程

使用 crontab 設定定時生成並顯示：

# 編輯排程
crontab -e

# 每天早上 8 點生成新圖片並顯示
0 8 * * * cd /home/pi/photopainter && venv/bin/python src/generate_picture.py output/ && venv/bin/python src/display_picture.py output/output.png

# 每 6 小時生成一次
0 */6 * * * cd /home/pi/photopainter && venv/bin/python src/generate_picture.py output/ && venv/bin/python src/display_picture.py output/output.png

# 開機時自動啟動 Web 介面
@reboot cd /home/pi/photopainter && venv/bin/python web/app.py &

按鍵控制

# 啟動按鍵控制器
python src/display_buttons.py
按鍵GPIO功能
AGPIO 5顯示最新圖片
BGPIO 6上一張圖片
CGPIO 16下一張圖片
DGPIO 24關機

API 文件

Web 介面提供 RESTful API，可用於整合其他系統：

方法路徑說明
POST/api/upload上傳圖片 (multipart/form-data, field: file)
POST/api/display顯示圖片 (JSON: {"filename": "..."})
GET/api/preview/<filename>取得 7 色量化預覽圖
POST/api/generate開始 AI 生成 (JSON: {"prompt", "prompt_file", "seed", "steps"})
GET/api/generate/status查詢生成進度
GET/api/images列出所有圖片
DELETE/api/images/<filename>刪除圖片
POST/api/clear清除螢幕
POST/api/sleep螢幕休眠
GET/api/status系統狀態
API 範例
# 上傳圖片
curl -F "file=@photo.jpg" http://pi:5000/api/upload

# 顯示圖片到電子紙
curl -X POST -H "Content-Type: application/json" \
  -d '{"filename": "photo.jpg"}' http://pi:5000/api/display

# 開始 AI 生成
curl -X POST -H "Content-Type: application/json" \
  -d '{"prompt": "a sunset", "steps": 5}' http://pi:5000/api/generate

# 查詢生成狀態
curl http://pi:5000/api/generate/status

故障排除

  1. 確認 SPI 已啟用：sudo raspi-config → Interface Options → SPI
  2. 檢查排線連接是否牢固
  3. 確認使用正確的 GPIO 腳位
  4. 測試：python -c "from lib.waveshare_epd import epd7in3f; e=epd7in3f.EPD(); e.init(); e.Clear(); e.sleep()"

  1. 確認 OnnxStream 已成功編譯：ls OnnxStream/src/build/sd
  2. 確認模型已下載：ls models/stable-diffusion-xl-turbo-1.0-anyshape-onnxstream/
  3. 確認 swap 空間足夠：free -h（建議 1024MB swap）
  4. 確認記憶卡剩餘空間：df -h

  1. 確認伺服器已啟動：python web/app.py
  2. 確認 Pi 的 IP 位址：hostname -I
  3. 確認防火牆允許 port 5000
  4. 嘗試本機存取：curl http://localhost:5000

  • AI 生成時溫度可達 70°C，屬正常現象
  • 建議加裝散熱片
  • 監控溫度：vcgencmd measure_temp
  • 若超過 80°C，請檢查散熱或減少生成頻率
